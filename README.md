# ⛔ DEPRECATED — See applejax-tv

This repository is no longer maintained. All development has moved to:

👉 **[joshuapointer/applejax-tv](https://github.com/joshuapointer/applejax-tv)**

The `applejax-tv` repo contains the complete project: the tvOS visualizer app, iPhone companion app, Metal renderer, UDP audio streaming, TestFlight CI, and all build scripts. This repo was an early M1-only scaffold and is now superseded.

## What was here?

- `apps/tvos/scripts/build-libprojectm-xcframework.sh` — tvOS xcframework builder
- `apps/tvos/scripts/sync-preset-pack.sh` — preset sync helper
- `apps/tvos/scripts/toolchains/tvos.cmake` — CMake toolchain for tvOS cross-compile
- `apps/tvos/README.md` — original M1-only documentation

All of the above (and much more) now lives in `joshuapointer/applejax-tv`.
